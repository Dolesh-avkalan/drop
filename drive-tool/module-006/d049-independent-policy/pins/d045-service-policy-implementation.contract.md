## Exact public API

- OPERATIONS=frozenset({'find','list','read','save'}), MAX_TRANSFER_BYTES=1048576.
- PolicyDeniedError(Exception): fixed public message 'access denied', never echo inputs.
- Frozen dataclass SourceGrant(alias:str, root:str, operations:frozenset[str], max_read_bytes:int=1048576, max_write_bytes:int=1048576). Root is trusted operator configuration, never a request parameter; field repr=False. alias nonempty ASCII identifier1..64 chars [A-Za-z0-9_-]. root a nonempty absolute POSIX string; reject NUL/backslash and empty/dot/dotdot components (except leading slash and root '/' itself). Reject nonstr with TypeError and malformed str with ValueError. NO os.path filesystem checks or symlink claims; LocalAdapter construction later checks real existence/no-follow and anchors each granted root. operations must be a nonempty frozenset of supported exact strings; reject mutable sets, unknown/nonstring members. Byte caps nonbool int1..MAX_TRANSFER_BYTES; read/write caps do not grant absent operations.
- Frozen dataclass AgentPolicy(agent_id:str, token_sha256:bytes, grants:tuple[SourceGrant,...]). token_sha256 field repr=False. agent_id same identifier grammar, token_sha256 exactly32 bytes (not bytearray), grants nonempty tuple, maximum32, exact SourceGrant instances, unique aliases within this agent. No mutable containers, implicit coercion or runtime filesystem work. TypeError for wrong types, ValueError for valid types with invalid values. Full constructor validation, all objects frozen.
- PolicyTable(agents:tuple[AgentPolicy,...]): nonempty tuple, maximum32; validates all entries, unique agent IDs and unique token digests. Make internal state immutable or private immutable copies, no externally mutable dictionaries. Duplicate token digest must fail (otherwise one credential could identify two agents). Never expose root/digest in repr/error messages.
- PolicyTable.authenticate(token:str)->AgentPolicy: accepts a raw bearer token value (HTTP Bearer parsing is later); ASCII32..256 visible chars codepoints33..126 only. Malformed/missing/wrong types or unknown token all raise PolicyDeniedError('access denied'), no value leakage. Hash once with hashlib.sha256 and compare to ALL configured digests using hmac.compare_digest; do not return on first match. Return the configured matching immutable AgentPolicy. No token retention/cache/logging. No promise that the full Python function is perfectly constant-time; compare_digest and bounded full scan only.
- PolicyTable.authorize(agent_id:str, source_alias:str, operation:str)->SourceGrant: trusted internal call after authentication, not an unauthenticated HTTP endpoint. Agent must exist, alias granted in that agent, op one of four AND in grant.operations; otherwise identical PolicyDeniedError. Validate arbitrary/wrong-type/unhashable request values without leaking KeyError/TypeError. Never fall back to another agent's grants or reveal whether a source exists elsewhere. Return only configured immutable grant. Two agents may use the same alias with different roots; registry later keys adapters by (agent_id,source_alias), never alias alone.

No request file IDs/prefix matching in this layer: future HTTP layer validates IDs using existing adapter behavior and uses a grant-specific anchored adapter constructed at startup. A request never chooses a host root; aliases are agent-scoped. This layer performs authentication and operation/alias authorization only; it is not a filesystem containment implementation.

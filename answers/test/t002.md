Relay check t002: in two short bullet points, name two benefits of running a task relay with coded browser steps instead of an LLM driving every click.

## Answer

- Speed and lower cost: Bypassing the LLM for every action eliminates high API token usage and the latency of waiting for inference between clicks.

- Deterministic reliability: Hardcoded steps guarantee consistent execution on stable UIs, removing the risk of LLM hallucinations or visual misinterpretations.
